# Skill: feature

## Description
Реализация новых функций и возможностей для Chrome Extension BPMN Diff. Сохраняет обратную совместимость и следует архитектуре проекта.

## When to use
- Пользователь просит "добавь", "новая фича", "реализуй", "создай"
- Требуется расширить функциональность расширения
- Нужно добавить новый UI элемент или поведение
- Требуется интеграция с новыми API

## Workflow

### 1. Уточнение требований
- Убедиться что требования понятны и полны
- Если критическая информация отсутствует — задать уточняющие вопросы
- Предложить варианты реализации если есть выбор

### 2. План реализации
- Описать шаги реализации
- Указать какие файлы будут затронуты
- Предложить архитектуру решения

### 3. Подтверждение
- Получить подтверждение плана от пользователя
- **НЕ начинать** реализацию без подтверждения для сложных изменений

### 4. Реализация
- Следовать плану
- Соблюдать стиль кода (code-style skill)
- Писать тесты если это уместно

### 5. Верификация
- Проверить что новая фича работает
- Убедиться что существующее поведение не сломано

## Rules

### При разработке:
1. **Следовать архитектуре** — не нарушать существующую структуру
2. **Сохранять совместимость** — не ломать существующий функционал
3. **Минимальные изменения** — не делать лишних изменений
4. **Чистый код** — следовать правилам code-style

### Integration points
- Новые компоненты должны интегрироваться с существующей архитектурой
- Использовать существующие провайдеры и утилиты где возможно
- Избегать дупликации логики

## Constraints
- ⚠️ **НЕ трогать** `libs/` — использовать как внешний API
- ⚠️ **НЕ менять** `manifest.json` без явного запроса
- ⚠️ **НЕ добавлять** новые зависимости
- ⚠️ **НЕ использовать** TypeScript, фреймворки, сборщики
- ⚠️ **НЕ менять** UX/UI без явного запроса
- ⚠️ **СОХРАНЯТЬ** обратную совместимость

## Project Context

### Тип проекта
Chrome Extension (Manifest V3) для визуального сравнения BPMN/DMN диаграмм в GitLab MR.

### Ключевые ограничения
- Plain JavaScript (ES6+), без сборщиков
- Content script работает на `gitlab.example.com/*` и `gitlab.com/*`
- Нет build step — vanilla JS

### Архитектура
```
Entry Point → App → Providers → Differs → UI
   (main.js)   |      |          |         |
               |      |          |         └─ bpmn-differ.js / dmn-differ.js
               |      |          └─ GitLabRepoProvider (data)
               |      └─ GitLabUIRepoProvider (buttons)
               └─ Dependencies (moddle, reloader, detector)
```
