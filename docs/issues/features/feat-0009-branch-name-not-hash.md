## Постановка

Для смерженного MR в `Branch` сейчас отображается хеш коммита целевой ветки. Передавать дифферу `targetBranchName` отдельным параметром (имя ветки).

## Контекст

- Код: `differ-params.js` — сейчас `this.targetBranchName = this.branchCommitId`, т.е. вместо имени ветки кладётся id коммита.
