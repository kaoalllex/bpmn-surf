title: Подпроцесс не подсвечивается, когда изменён только вложенный элемент
priority: medium
status: open

## Постановка

Если изменения находятся внутри подпроцесса (в т.ч. подпроцесс внутри подпроцесса),
синим подсвечивается только сам изменённый дочерний элемент, а родительский
подпроцесс — нет. На свёрнутом подпроцессе это особенно мешает: его детей не видно,
и об изменениях внутри ничего не сигнализирует.

Пример (диаграмма «Периодические создания заявления КЭП»): изменения внутри шага
«Выпустить УЗ» — он подсвечивается, но охватывающий подпроцесс «Выпуск УЗ» не
подсвечивается.

Ожидание: при изменении вложенного элемента подсветка должна доходить и до
родительских подпроцессов (на всех уровнях вложенности), чтобы изменение было видно
сверху, а не только на листе.

## Контекст

- Регрессия: раньше подсвечивался охватывающий подпроцесс, но не сам изменённый шаг
  внутри. Подсветку листового элемента починили (предположительно в районе фиксов
  диффера от 2026-06-10…12: `188314a`, `3b35624`), но при этом потеряли подсветку
  родительского подпроцесса.
- Текущее поведение **намеренно закреплено** кодом и тестом:
  - `bpmn-xml-comparator.js:282-289` — `#compareNodes()`: дети подпроцесса исключаются
    из diff самого подпроцесса («Do not compare children of subprocesses…»), сравниваются
    отдельно в `compare()`. Поэтому в `changedShapeIds` попадает только дочерний элемент.
  - `diff-highlighter.js` — подсвечивает ровно элементы из вычисленного набора, без
    обхода вверх по дереву (нет распространения подсветки на предка).
  - `test/bpmn-xml-comparator-camunda.test.js` — тест `flags a changed inner element
    but not the enclosing subprocess` явно требует, чтобы подпроцесс НЕ попадал в
    `changedShapeIds` при изменении только ребёнка. При фиксе этот тест нужно
    пересмотреть/обновить.
- Направление фикса: при обнаружении изменения вложенного элемента добавлять его
  предков-подпроцессы в набор для подсветки (распространение вверх по дереву,
  предположительно в `bpmn-xml-comparator.js#compare()`).
- Проверить общие классы differ-страницы и оба differ'а (BPMN/DMN) — подсветка общая.
