## Постановка

Сейчас по кнопке **Highlight On** все diff-элементы на схеме сначала на 2 секунды
получают жирную статичную обводку (`highlight-diff-big`, 15px), затем обводка
становится тонкой постоянной (`highlight-diff`, 3px). Фаза привлечения внимания —
статичная «жирная вспышка».

Нужно, чтобы вместо статичной жирной фазы элементы **мигали** так же, как мигает
текущий найденный элемент в поиске (FEAT-0006, `search-match-current` —
пульсирующая анимация ширины обводки + лёгкое свечение). После завершения
мигания подсветка остаётся прежней тонкой постоянной обводкой.

**Цвет подсветки не менять** — остаётся текущий бирюзовый (`hsl(180, 100%, 70%)`),
меняется только характер привлекающей внимание фазы: статичная толщина → пульс.

## Контекст

- Эталон мигания: `.search-match-current` + `@keyframes search-match-pulse`
  в `src/differ/styles.css` (FEAT-0006). Анимация `0.45s ease-in-out 2` +
  `drop-shadow`.
- Кнопка Highlight: `DiffHighlighter.setEnabled()`
  (`src/differ/bpmn/diff-highlighter.js`), двухфазная логика с `setTimeout(2000)`.
- ⚠️ `BIG_HIGHLIGHTING_MARKER` (`highlight-diff-big`) используется **ещё и** в
  `changes-table-view.js` — для подсветки одного выбранного в таблице элемента
  (держится до сброса выделения). Это **другой** сценарий, его трогать не нужно:
  пульс вводится только для фазы привлечения внимания кнопки Highlight.

## План работ

1. **CSS** (`src/differ/styles.css`): добавить класс `.highlight-diff-pulse
   .djs-outline` с тем же бирюзовым цветом, что у `highlight-diff`, лёгким
   свечением (`drop-shadow`) и пульсирующей анимацией ширины обводки по аналогии
   с `search-match-pulse` (отдельный `@keyframes highlight-diff-pulse`, чтобы не
   конфликтовать с поиском). Подобрать число итераций так, чтобы окно мигания
   совпадало с таймаутом перехода к тонкой подсветке.
2. **diff-highlighter.js**: ввести `PULSE_HIGHLIGHTING_MARKER = 'highlight-diff-pulse'`.
   В `setEnabled(true)` вместо `BIG_HIGHLIGHTING_MARKER` навешивать пульс-маркер,
   по таймауту снимать его и ставить тонкий `HIGHLIGHTING_MARKER`. В ветке
   выключения снимать пульс-маркер. `BIG_HIGHLIGHTING_MARKER` оставить для
   `changes-table-view.js`.
3. **Согласовать таймаут** перехода к постоянной подсветке с длительностью
   анимации, чтобы не было статичного «зависания» жирной обводки между концом
   пульса и снятием маркера.
4. **Тесты/проверка**: прогнать `npm test`; при наличии — обновить структурные
   тесты. Ручная проверка на реальной схеме (мигание → тонкая постоянная).

### 2026-06-15 · claude-opus-4-8 · ветка `feature/ux-0006-blink-highlight`

Фаза привлечения внимания кнопки Highlight теперь мигает вместо статичной жирной
обводки. В `diff-highlighter.js` введён `PULSE_HIGHLIGHTING_MARKER`
(`highlight-diff-pulse`) и `PULSE_DURATION_MS = 2000`; `setEnabled(true)` вешает
пульс-маркер вместо `BIG_HIGHLIGHTING_MARKER`, по таймауту меняет на тонкий
постоянный `HIGHLIGHTING_MARKER`. В `styles.css` добавлен класс
`.highlight-diff-pulse` (тот же бирюзовый `hsl(180,100%,70%)` + `drop-shadow`) и
`@keyframes highlight-diff-pulse` (пульс ширины обводки 3↔12px, `0.5s × 4 = 2s`,
синхронно с таймаутом). `BIG_HIGHLIGHTING_MARKER` не тронут — остался для
подсветки выбранной строки в `changes-table-view.js`. Все тесты зелёные (619).
Анимацию имеет смысл проверить вручную в браузере на реальной схеме.
