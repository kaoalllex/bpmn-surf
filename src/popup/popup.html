Как обновить
  1. Обновите файлы расширения:
    git pull
    Не через git? Открыть страницу загрузки и заменить файлы в папке расширения.
  2. Нажмите «Перезагрузить расширение» — оно перечитает файлы с диска.

Расширение не меняет свои файлы само — байты на диск приносите вы (это ограничение «load unpacked»). Перезагрузка применяет уже обновлённые файлы.
