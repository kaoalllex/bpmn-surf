Where the extension runs. Chrome asks you to allow each site you add, and tabs that are already open need a reload before the buttons appear. A site you remove can stay listed in chrome://extensions → Site access — that record is Chrome's own, the extension no longer runs there.

    How this project marks the class serving an external task, so the diagram can link to it. Delegates need no annotation and always work.

      Topic from the class name

      @YourAnnotation class ReserveStockHandler → topic reserveStockHandler: the annotation names no topic, the framework lower-cases the class name's first letter. Stock Camunda has nothing like this — add a name only if your framework does.

        Export writes the sites and the annotations to a JSON file you can hand to a colleague. Importing applies the annotations at once; the sites still need Chrome's permission, so a button appears for you to allow them.
