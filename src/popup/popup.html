How to update
  1. Update the extension files:
    git pull
    Not using git? Open the download page and replace the files in the extension folder.
  2. Click "Reload extension" — it will re-read the files from disk.

The extension does not change its own files — you bring the bytes to disk yourself (a limitation of "load unpacked"). Reloading applies the already updated files.
