# bpmn-diff

Google Chrome extension that enables visual comparison of BPMN 2.0 diagrams 
included in GitLab merge requests.

## Issues (done)
- скрыты контролы редактирования, вылезающие при выборе эл-та на схеме (они не нужны и мешали только)
- обновлены версии либ (bpmn-js и др.)
- отображение полосы прокрутки для панели пропертей, когда все не влезает
- автоматический выбор ранее выбранного элемента, если в одном из бранчей его нет (раньше выбор слетал)
- разные мелкие фиксы
